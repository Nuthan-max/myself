- **Hero Section:** Three.js 3D geometric particle lattice, oversized display typography, floating status pills.
- **Editorial About Section:** Asymmetric layout, academic manifesto, and core research focus areas.
- **Academic Timeline:** Verifiable timeline of CBSE Class 10, Karnataka State Board Higher Secondary (92% Distinction), and LPU B.Tech ECE.
- **Interactive Skills Directory:** Categorized by Programming, Electronics & Hardware, Development, and Emerging Tech.

  2. *AI-Based Structural Health Monitoring* — Cyber-physical vibration & strain diagnostics using ESP32, MPU6050, and KiCad PCB schematics.
  3. *SIH Water Body Monitoring System* — Computer vision plastic detection & aquatic telemetry buoy (Team *Byte Me*).
- **Hackathons (Dark Section):** High-intensity sprints with Team Byte Me, Smart India Hackathon national stage participation.
- **Sports & Extracurriculars:** Cricket Vice-Captaincy, Singles Badminton, District Rapid Chess, and Track & Field 4x100m relay silver medal.
- **Digital Certificate Archive:** Category filters, fullscreen credential viewer, and zoom controls.
- **Visual Photography Gallery:** Asymmetric editorial masonry grid with full-screen lightbox.
- **Contact Section & Official CV Generator:** One-click email copy, interactive message dispatch, and print/PDF-ready Curriculum Vitae modal.

## 04. Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Run
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
