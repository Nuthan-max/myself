# Nuthan G — Portfolio

A React and Vite portfolio for Nuthan G, a first-semester Electronics and Communication Engineering student at Lovely Professional University.

## Color palette

The interface follows a 60–30–10 balance:

- 60% warm ivory (`#F7F2EB`)
- 30% beige and soft gray (`#EAE2D6`, `#EEEEEE`)
- 10% olive accent (`#8B9A6E`)

## Portfolio content

The site includes profile and education details, interests and tools explored, project and hackathon status, supplied certificate PDFs, and a personal portrait. Unconfirmed project outcomes and certificate metadata are not presented as facts.

## Development

Requires Node.js 18 or newer and npm.

```bash
npm install
npm run dev
npm run build
npm run preview
```
